# Security Policy

## Reporting a concern

If you discover a security or privacy issue in Human Sense AI, please avoid posting sensitive details publicly. Contact the repository owner privately through GitHub's profile contact options, if available.

Include a concise description of the issue, its potential impact, and steps to reproduce it without sharing real people's camera footage or other personal data.

## Scope

Human Sense AI is a hackathon prototype, not a security-audited product. Do not use it to make consequential decisions about people. Camera access should be granted only to software and users you trust.
